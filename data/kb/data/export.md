# Экспорт заметок

Выгрузить все заметки: Настройки → Данные → Экспорт. Экспорт доступен на всех тарифах, включая Бесплатный.

Форматы:

- **Markdown** — ZIP-архив, каждая заметка — отдельный файл .md, вложения лежат в папке рядом. Подходит для переноса в другие приложения.
- **PDF** — один файл со всеми заметками. Подходит для печати и архива.
- **HTML** — архив с веб-страницами, которые открываются в любом браузере.

Когда архив готов, на почту приходит ссылка. Ссылка действует 7 дней. Большие аккаунты готовятся до часа.

Запускать полный экспорт можно раз в 24 часа. Одну заметку выгрузить можно в любой момент: открой её → меню «…» → Экспорт.

Заметки из корзины в экспорт не попадают. Если они нужны, сначала восстанови их.
