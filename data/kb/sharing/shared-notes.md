# Общий доступ к заметкам

Поделиться заметкой: открой её → «Поделиться» → «Доступ по ссылке». Выбери, что может человек со ссылкой: читать или редактировать.

Право на редактирование есть только на тарифах Плюс и Команда. На Бесплатном тарифе ссылкой можно поделиться только на чтение.

Чтобы редактировать заметку, человеку нужен аккаунт «Тетради», подойдёт и Бесплатный. Читать по ссылке можно без аккаунта.

Закрыть доступ: «Поделиться» → «Отключить ссылку». Старая ссылка сразу перестанет работать.

В тарифе «Команда» есть общие папки: всё, что в них лежит, видят участники команды по своим ролям. Ссылки для людей вне команды владелец может запретить: Настройки → Команда → Безопасность.

Одновременно заметку могут править до 20 человек.
