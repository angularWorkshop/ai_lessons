# Тема 1.3 — Надёжный клиент: таймауты, отмена, повторы

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/llm.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты темы 1.1 должны остаться зелёными.
3. `npm run ctrl-c` — длинный запрос, который можно отменить по Ctrl+C. `npm run hello` — короткий запрос, как в теме 1.1.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
