# Тема 1.1 — Клиент к LLM

Задание — в описании практики на платформе. Коротко:

1. `npm install`
2. `npm run start:dev` — проверка перезапускается при каждом сохранении.
3. Пиши код в `src/llm.ts` по шагам 1–5, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`.
4. На своём компьютере: `cp .env.example .env`, заполни `.env`, затем `npm run hello`.

Тесты (`npm test`) не ходят в сеть и не требуют ключа.
