# Тема 12.5 — События, trace, replay

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/harness/trace.ts` и `src/harness/replay.ts` по шагам 1–5, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run harness` пишет трейс сессии в `playground/.agent/traces/<id>.jsonl`. `npm run trace` — последняя сессия по времени, токенам и деньгам, `npm run trace <id>` — любая.
4. `npm run replay` — та же сессия ещё раз, без сети и без ключа. `npm run replay -- --max-steps 3` — что было бы с другим лимитом.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
