# Тема 11.2 — Пишем MCP-сервер

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/mcp/server.ts` и `src/mcp/tools.ts` по шагам 1–5, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run mcp-demo` — клиент поднимает сервер, получает список инструментов, и модель сама вызывает инструмент на сервере.
4. `npm run mcp-server` — сервер в терминале: можно вставлять JSON-строки руками.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
