# Тема 12.1 — Что такое harness

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/harness/create.ts`, `src/harness/confirm.ts` и `src/harness/run.ts` по шагам 1–5, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run harness` — твой агент для кода в терминале поверх `createHarness`: проект `playground/`, права, план, память, скиллы, субагент, MCP.
4. `npm run harness -- --mode auto -p "Почини падающий тест в проекте."` — то же без человека. `npm run reset-playground` вернёт `playground/` как было.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
