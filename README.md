# Тема 9.1 — SKILL.md

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Напиши разбор SKILL.md в `src/skills/frontmatter.ts` и `src/skills/skill.ts` по шагам 1–5, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run check-skills` — проверяет все скиллы в папке `skills/` и считает, сколько текста из них уходит в каждый запрос, а сколько — только по требованию.

Модель в этой теме не нужна: формат проверяется кодом.
