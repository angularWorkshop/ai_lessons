# Тема 12.3 — Сессии и resume

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/harness/session.ts` по шагам 1–5, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run harness` — каждая сессия пишет журнал в `playground/.agent/sessions/<id>.jsonl`. В конце harness печатает, как её продолжить.
4. `npm run harness -- --continue` — продолжить последнюю сессию, `npm run harness -- --resume <id>` — любую. С `-p` работает и без человека.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
