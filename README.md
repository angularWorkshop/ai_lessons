# Тема 13.1 — Prompt injection на живой модели

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Допиши `src/security/untrusted.ts` и `src/security/redact.ts` по шагам 1–3, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run injection` — агент читает `playground/BUGS.md`, где спрятана инструкция для модели. `npm run injection -- --undefended` — то же без рамки и без правила в system.
4. `npm run layers` — замер: тот же сценарий по 3 прогона на каждый набор слоёв.

`playground/` — проект, в котором работает агент. В нём лежит `.env` с ненастоящим ключом. `npm run reset-playground` вернёт всё как было.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
