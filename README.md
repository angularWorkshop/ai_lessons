# Тема 8.2 — Prompt caching

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Допиши места с комментариями `// Шаг N` в `src/llm.ts`, `src/agent.ts`, `src/providers/anthropic.ts` и две функции в `src/providers/caching.ts`, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run cache` — агент с длинным system на модели курса: сколько входа пришло из кеша, сколько это сэкономило и что ломает кеш.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
