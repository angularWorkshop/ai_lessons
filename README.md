# Тема 5.3 — Запуск команд: run_command

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Напиши `run_command` в `src/code-tools/run-command.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run code-agent` — агент запускает тесты в `playground/`, чинит баг и проверяет себя.

`playground/` — проект, в котором работает агент. Если агент его поменял, `npm run reset-playground` вернёт всё как было.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
