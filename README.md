# Тема 10.4 — Параллельные субагенты

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/subagents/budget.ts`, `src/subagents/task-tool.ts` и `src/todo/workspace.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run parallel` — десять субагентов параллельно, общий бюджет токенов. `npm run parallel -- --shared` и `--shared --check` — дети пишут в один файл.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
