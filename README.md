# Тема 4.4 — Несколько вызовов за шаг

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Напиши `mapLimit` в `src/concurrency.ts` и `#execute` в `src/agent.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем и твои сценарии из темы 4.3 должны остаться зелёными.
3. `npm run agent "Который час в Москве, Лондоне и Токио?"` — модель присылает три вызова за шаг, агент исполняет их одновременно.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
