# Тема 3.3 — Ошибка инструмента как данные для модели

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `Toolbox.execute` и `truncate` в `src/tools.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run tool-errors` — модель получает текст ошибки и исправляет вызов сама.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
