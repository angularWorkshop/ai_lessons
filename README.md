# Тема 4.2 — Лимиты, причины остановки, зацикливание

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `Agent.run` и `RepeatGuard` в `src/agent.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run limits` — агент упирается в лимит шагов и подводит итог. `npm run agent "задача"` и Ctrl+C — агент останавливается, а не падает.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
