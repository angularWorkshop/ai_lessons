# Тема 10.2 — Субагент как инструмент

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/subagents/task-tool.ts` и `src/subagents/print-child.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run subagent` — ведущий агент раздаёт ревью модулей субагентам, их строки идут с префиксом. `npm run subagent -- --solo` — та же задача одним агентом.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
