# Тема 10.3 — Планировщик, исполнитель, ревьюер

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/subagents/verdict.ts` и `src/subagents/roles.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run roles` — три роли чинят `hexToRgb`, ревьюер выносит вердикт. `npm run roles -- --solo` — та же задача одним агентом.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
