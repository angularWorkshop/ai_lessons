# Тема 8.1 — Свой формат сообщений и адаптеры

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Напиши четыре функции в `src/providers/anthropic.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run providers` — агент решает задачу через шлюз курса и печатает свой последний запрос в формате Anthropic Messages API.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью. Ключа к Anthropic в курсе нет: адаптер проверяют тесты на примерах из документации Anthropic.
