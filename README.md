# Тема 2.1 — Строение system prompt

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/prompt.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты секции 1 должны остаться зелёными.
3. `npm run prompt` — три system prompt на одном и том же diff: размытый, многословный и собранный из разделов.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
