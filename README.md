# Тема 12.2 — Настройки по слоям

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/harness/settings.ts` по шагам 1–5, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. Настройки проекта — `playground/.agent/settings.json`. Свои правки клади в `playground/.agent/settings.local.json`: он в `.gitignore`.
4. `npm run harness -- -p "Почини падающий тест в проекте."` — без человека правка получит честный отказ. Добавь в локальный слой `"allow": ["edit_file(src/**)"]` и запусти ещё раз.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
