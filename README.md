# Тема 11.1 — JSON-RPC по stdio

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/mcp/jsonrpc.ts` по шагам 1–5, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run rpc-demo` — два процесса обмениваются сообщениями, каждая строка видна в терминале.
