# Тема 3.2 — Интерфейс Tool и реестр

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/tools.ts` (шаги 1–2) и калькулятор в `src/demo-tools.ts` (шаг 3), пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run tools` — инструменты из реестра на настоящей модели.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
