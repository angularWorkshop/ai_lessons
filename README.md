# Тема 7.5 — Модели с рассуждениями

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Добавь `reasoning` в запрос и ответ в `src/llm.ts`, напиши `withReasoning` и `answerWithEscalation` в `src/context/reasoning.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`.
3. `npm run reasoning` — одна задача без рассуждений и с ними: токены, цена, время и правильность ответа.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
