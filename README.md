# Тема 11.3 — MCP-клиент в своём агенте

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/mcp/client.ts`, `src/mcp/agent-tools.ts` и `src/mcp/config.ts` по шагам 1–5, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run agent "Сколько файлов с тестами (*.test.ts) в папке tests? Запиши ответ заметкой в NOTES.md."` — агент поднимает MCP-сервер из `mcp.json` и решает задачу его инструментами.
4. `npm run mcp-server` и `npm run mcp-demo` — сервер и ручной клиент из темы 11.2 на месте.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
