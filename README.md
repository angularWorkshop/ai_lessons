# Тема 6.1 — Стриминг внутри цикла

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Собери вызовы из кусочков в `src/tool-call-deltas.ts`, научи `chatStream` в `src/llm.ts` инструментам, допиши `stream` в `llmProvider` и `#ask` в `src/agent.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run tool-chunks` — сырые кусочки вызовов из стрима. `npm run agent "Который час в Москве и в Токио?"` — агент печатает ответ по мере генерации.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
