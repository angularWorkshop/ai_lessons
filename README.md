# Тема 4.1 — Цикл агента

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Напиши `llmProvider` в `src/provider.ts` и `Agent.run` в `src/agent.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run agent "задача"` — агент решает задачу на настоящей модели и печатает каждый шаг.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
