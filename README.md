# Тема 10.1 — Todo-инструмент

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/todo/todo.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run todo` — агент готовит релиз библиотеки по плану, план обновляется в терминале. `npm run todo -- --no-plan` — та же задача без плана.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
