Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Шаг 1 — в `src/llm.ts`, шаги 2–5 — в `src/structured.ts`. Дописывай, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run json` — «верни JSON» в тексте промпта против `response_format` + zod на трёх настоящих diff.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
