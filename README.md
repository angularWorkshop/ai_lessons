# Тема 13.2 — Песочница для команд

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Допиши `src/security/sandbox.ts` по шагам 1–3, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run secure-agent "почини тест в playground"` — агент со всей защитой секции 13: права, рамка, правило, маскировка секретов и `run_command` в песочнице. Режимы: `--mode=read-only`, `--mode=ask` (по умолчанию), `--mode=auto`.

`playground/` — проект, в котором работает агент. `npm run reset-playground` вернёт всё как было.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
