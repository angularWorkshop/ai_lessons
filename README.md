# Тема 6.2 — Прерывание

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Напиши `untilAborted` в `src/interrupt.ts`, подключи его в `#execute` в `src/agent.ts`, допиши `send` в `src/conversation.ts` и клавиши в `src/keys.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run agent` — разговор с агентом. Esc или Ctrl+C останавливают задачу, а следующую можно писать сразу.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
