# Тема 12.6 — Бюджеты, повторы, checkpoint и откат правок

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/harness/checkpoints.ts`, `budget.ts`, `commands.ts` и `recovery.ts` по шагам 1–5, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run harness` — итог секции: свой мини-Claude Code. В разговоре `/rewind` откатывает правки последней задачи, `/cost` показывает деньги за сессию.
4. Бюджет сессии — `"limits": { "maxCostUsd": 0.01 }` в `playground/.agent/settings.local.json`.
5. `npm run crash-demo` — процесс агента падает посреди задачи, а `--continue` восстанавливает работу по журналу и checkpoint.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
