# Тема 9.3 — Как написать скилл и проверить, что он срабатывает

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Напиши trigger-eval в `src/skills/trigger-eval.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run trigger-eval` — набор запросов из `src/skills/trigger-cases.ts` против описаний скилла `failing-test`: сколько раз он сработал там, где нужно, и сколько — зря.
4. Перепиши описание в `skills/failing-test/SKILL.md` и замерь снова.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
