# Тема 9.2 — Загрузчик скиллов

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Напиши поиск скиллов и их список для system prompt в `src/skills/loader.ts`, инструменты `load_skill` и `read_skill_file` в `src/skills/skill-tools.ts` и сборку агента в `src/skills/agent-setup.ts` по шагам 1–5, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run skill-agent` — агент сам загружает скилл `commit-message` и пишет сообщение коммита по его правилам. Свою задачу передай в кавычках, файл — через `@`: `npm run skill-agent "Что не так?" @examples/failing-test.txt`.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
