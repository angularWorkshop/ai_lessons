# Тема 14.2 — LLM-as-judge

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Допиши `src/evals/judge.ts` по шагам 1–5, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run judge` — калибровка судьи на 12 сообщениях коммита с разметкой человека, без рубрики и с рубрикой, и сравнение пар в двух порядках.
4. `npm run evals` — набор задач для агента из темы 14.1 на месте.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
