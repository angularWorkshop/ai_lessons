# Тема 7.4 — Память между сессиями

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Напиши `MemoryStore`, инструмент `remember` и `memorySection` в `src/context/memory.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`.
3. `npm run memory` — две сессии агента: во второй он помнит то, что узнал в первой. Память лежит в `.agent/memory.json`.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
