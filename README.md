# Тема 5.4 — Права: allow / ask / deny

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Напиши политику, `GuardedToolbox` и вопрос в терминале в `src/code-tools/` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run code-agent "почини тест в playground"` — агент читает, правит и запускает тесты, а перед правкой и командой спрашивает тебя. Режимы: `npm run code-agent -- --mode=read-only "…"`, `--mode=auto`.

`playground/` — проект, в котором работает агент. Если агент его поменял, `npm run reset-playground` вернёт всё как было.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
