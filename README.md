# Тема 14.1 — Evals: набор задач и автопроверка

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Допиши `src/evals/workspace.ts`, `src/evals/checks.ts`, `src/evals/runner.ts` и `src/evals/report.ts` по шагам 1–5, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. `npm run evals` — агент для кода решает шесть задач из `evals/tasks/`, по три прогона на задачу. `npm run evals -- --runs=1 --task=slugify --keep` — один прогон одной задачи, копия проекта остаётся для разбора.

Задачи лежат в `evals/tasks/<id>/`: `project/` видит агент, `check/` — тесты проверки, `solution/` — эталон. Агент работает в копии во временной папке, сами задачи не меняются.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
