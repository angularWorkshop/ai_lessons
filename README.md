# Тема 12.4 — Хуки до и после вызова инструмента

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/harness/hooks.ts` и хуки в `src/harness/settings.ts` по шагам 1–5, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты прошлых тем должны остаться зелёными.
3. Хуки проекта — в `playground/.agent/hooks/`, подключены в `playground/.agent/settings.json`: запрет правок сгенерированных файлов, проверка тестами после `edit_file`, лог команд в `playground/.agent/commands.log`.
4. `npm run harness -- -p "В src/generated/promo-codes.ts добавь промокод SPRING."` — посмотри, кто остановит правку.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
