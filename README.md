# Тема 7.2 — Compaction

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Напиши `findSplit`, `renderTranscript`, `summarize` и `Compactor.prepare` в `src/context/compaction.ts` по шагам 1–4, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`.
3. `npm run compact` — агент читает три файла, история перерастает порог, модель пишет сводку, а агент доделывает задачу по ней.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
