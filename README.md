# Тема 4.3 — Тесты агента без сети: ScriptedProvider

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Напиши `textReply`, `toolReply` и `ScriptedProvider` в `src/testing/scripted-provider.ts` (шаги 1–2), а потом свои тесты агента — сценарии в `tests/agent-scenarios.ts` (шаги 3–4).
3. Сценарий должен пройти на настоящем агенте и упасть на каждом сломанном агенте из `tests/support/broken-agent.ts`. Этот файл не меняй.

Модель в этой теме не нужна: все тесты работают без сети.
