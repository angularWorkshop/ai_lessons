# Тема 3.1 — Tool calling руками

Задание — в описании практики на платформе. Коротко:

1. Проверка запускается сама и перезапускается при каждом сохранении (`npm run start:dev`).
2. Дописывай `src/llm.ts` по шагам 1–3, пока не увидишь `ASSIGNMENT STATUS: COMPLETED`. Тесты секции 1 должны остаться зелёными.
3. `npm run tool-call` — один полный круг на настоящей модели: вопрос, `tool_calls`, результат инструмента, ответ.

Модель уже подключена: платформа сама кладёт в проект `.env` с адресом, ключом и моделью.
