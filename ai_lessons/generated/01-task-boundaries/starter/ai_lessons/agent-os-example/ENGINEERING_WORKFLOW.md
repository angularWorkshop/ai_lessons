# Working Loop

1. Write a goal, exact scope, and observable acceptance.
2. Load the minimal relevant context and inspect the existing diff.
3. Make one bounded change in a separate exercise copy.
4. Run the profile's verification command and retain its exit code.
5. Review the diff and failures; repair within the agreed budget.
6. Report changed files, actual evidence, skipped checks, and remaining risk.

Stop for missing acceptance, new permissions, irreversible operations, or an
exhausted budget. A green configuration simulation is not command evidence.
