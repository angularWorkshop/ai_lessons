This is a teaching example, not a runtime or a security sandbox.
Read ENGINEERING_WORKFLOW.md, PROJECTS/demo.json, the selected role and skill,
then KNOWLEDGE/projects/demo/README.md. Project-specific commands belong in the
profile, not in copied prompts. Do not load the user's real .agents directory.
