# Блог

`slugify(title)` из `src/slug.js` делает адрес статьи из заголовка: «Hello, World!» → `hello-world`.

Правила:

- в адресе только строчные латинские буквы, цифры и дефис;
- всё остальное — пробелы, знаки препинания, другие алфавиты — разделитель; несколько разделителей подряд дают один дефис;
- в начале и в конце дефисов нет;
- адрес не длиннее 40 символов: длинный обрезаем, и если после обрезки на конце дефис — убираем его;
- если букв и цифр не осталось вовсе — адрес `untitled`.
